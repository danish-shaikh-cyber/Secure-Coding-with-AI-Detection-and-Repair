## 1. Project Overview & Research Questions

This platform replicates the exact methodology, dataset snapshots, static analysis tools, and evaluation metrics described in Belozerov et al. (2026), addressing the paper's three central research questions:

- **RQ1: How secure is the code generated by GPT in the DevGPT dataset?**  
  Analyzes 2,315 source files in C, C++, and C# across two snapshots (`snapshot_20231012` and `snapshot_20240514`). Identifies 114 candidate files flagged by scanners, yielding **56 manually confirmed vulnerabilities across 48 files** spanning 23 distinct CWE types.
- **RQ2: How effective are LLMs in detecting and correcting security issues when explicitly asked to do so?**  
  Compares longitudinal performance between October 2024 (GPT-4o: 56.3% detected / 53.1% repaired) and September 2025 (GPT-4.1: 82.1% / 75.0%; GPT-5: 78.6% / 78.6%; Claude Opus 4.1: 80.4% / 76.8%).
- **RQ3: Do developers provide more vulnerable code, or does GPT generate more insecure code during interactions?**  
  Investigates provenance bias: **25 confirmed flaws (44.6%)** originated from user prompts vs. **31 confirmed flaws (55.4%)** in GPT outputs. Models demonstrated higher fix rates on human code (88%) than on self-generated code (74%), illustrating self-correction limits.

                                       |
                                       v
+-----------------------------------------------------------------------------------+
| 3. FINDING NORMALIZATION & DEDUPLICATION                                          |
|    - Unified schema: {file, line, col, scanner, rule, cwe, severity, snippet}     |
+-----------------------------------------------------------------------------------+
                                       |
                                       v
+-----------------------------------------------------------------------------------+
| 4. AI-ASSISTED VULNERABILITY REPAIR (Zero-Shot Section 6.2 Prompt)                |
|    - Local Ollama (qwen2.5-coder, deepseek-coder) OR Hosted OpenAI / Anthropic    |

                                       |
                                       v

## 3. Technology Stack

- **Backend:** Python 3.11, FastAPI, Pydantic v2, SQLAlchemy, SQLite3.
- **Frontend:** React 18, Vite 6, Tailwind CSS, Monaco Editor, Lucide Icons.
- **Static Scanners:** Flawfinder 2.0.20, Semgrep, Cppcheck, Snyk, ESLint.
- **Compilers:** MinGW GCC 6.3.0, G++ 6.3.0, .NET SDK.
- **AI Engines:** Local Ollama (`http://localhost:11434`), OpenAI API (`gpt-4.1`, `gpt-4o`), Anthropic API (`claude-opus-4-1`).

## 4. Installation & Quick Start

### Prerequisites
- Python 3.11+ (in virtual environment `.venv`)
- Node.js 18+ and npm
- Optional: MinGW GCC/G++ on PATH for syntax checking
- Optional: Local Ollama running coding models for offline inference

### Running the Services

1. **Activate Virtual Environment & Install Dependencies:**
   ```bash
   .venv\Scripts\activate
   pip install -r backend/requirements.txt
   npm --prefix frontend install
   ```

2. **Start Backend Server:**
   ```bash
   .venv\Scripts\uvicorn.exe backend.app.main:app --host 127.0.0.1 --port 8000 --reload
   ```
   *Swagger API Documentation available at: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)*

3. **Start Frontend Development Dashboard:**
   ```bash
   npm --prefix frontend run dev
   ```
   *Interactive Web Dashboard available at: [http://localhost:5173](http://localhost:5173)*

4. **Run Automated Test Suite:**
   ```bash
   .venv\Scripts\python.exe -m pytest tests/
   ```
